Balance Sheet Audit Trail

Trace every SOFP figure back to its Trial Balance accounts and General Ledger transactions.

1. Choose your data source

Pick one source for this run — upload the same three Excel files as always, or pull posted entries directly from Odoo for a period. Whichever you choose, the audit trail below is built and checked exactly the same way.

2. Upload the workbook

Upload the Excel workbook containing the Statement of Financial Position (SOFP), Trial Balance (TB) and General Ledger (GL) sheets. Nothing is stored beyond this browser session; the file is only kept in server memory while you work with it.

2. Pull from Odoo

Give the reporting period (e.g. one calendar month). The tool connects to the staging Odoo instance using the connection already configured for it — no login or API key is needed here. Only posted (validated) journal entries are included; drafts are left out. If Odoo has no posted entries for the period, you'll be told rather than shown an empty or misleading report.

3. Confirm the sheets

These were guessed from the sheet names in your workbook — change any that are wrong before running the reconciliation.

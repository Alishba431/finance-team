Admin Gmail sign-in and invoice sheet

Enter the admin Gmail address and a Gmail App Password (Google Account → Security → 2-Step Verification → App Passwords — a 16-character code you generate yourself, no developer setup needed), then upload the invoice breakdown sheet. Neither the email nor the app password is saved anywhere — you re-enter them every run, and the password field is cleared as soon as this page reloads.

Paste it exactly as Google shows it — spaces are fine (e.g. "abcd efgh ijkl mnop") and will be removed automatically. Don't have one yet? Create a Gmail App Password (requires 2-Step Verification to already be turned on for that account).

If your sheet has a "Partner (Vendor)" column, that vendor name is used to search Gmail; the Enterprise/department column is still shown in the report. Sheets with only an Enterprise column match on that instead, as before.

What's an App Password?

A 16-character code from Google Account → Security → 2-Step Verification → App Passwords (requires 2-Step Verification to be on). Paste it exactly as shown — spaces are fine and removed automatically. Nothing is saved; you re-enter it every run. Create one →

What columns does it need?

A header row (anywhere in the first 10 rows) with a Partner/Vendor or Enterprise column, a description, a date, and an amount. Vendor is preferred for the Gmail search when both exist.
